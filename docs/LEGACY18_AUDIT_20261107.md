# 2019~20 추가 18곳 추출·원문 대조 보고서 (2026-11-07)

## 입력과 재빌드

- 최신 data/raw의 추가 입력은 CSV 30개와 빛의벙커 HWP 1개. data/raw에 zip은 없음. 바탕화면의 장소 zip 13개에는 좌표/지점 CSV·사진·공통 `제주무장애여행 데이터셋 가이드문서.hwp`만 있고 장소별 서술형 HWP는 없음. 공통 가이드를 장소별 시설 설명으로 사용하지 않음.
- 공통 가이드 관광지 ID 표를 근거로 숫자 CSV를 manifest_override.csv에 연결. 원본 CSV·HWP·zip은 변경하지 않음. 가이드 확인용 사본은 배포 제외 output/validation/narrative18/common_dataset_guide.hwp.
- `python build_db.py --catalog catalog.xlsx` 완료. 숫자 좌표형/지점형·2020 한글 열·Title 대문자형을 지원. HWP 1곳과 지점 CSV의 서술 원문을 추출. 단순 좌표에서 시설 유무를 추정하지 않음.
- 성공/부분성공은 파일 해독 여부와 필수 3항목의 명시 근거 확보 여부를 구분한 결과. 부분성공은 원문에 없는 항목을 미확인으로 남긴 경우이며 시설이 없다는 뜻 아님. 좌표만 있는 -1 CSV 자체는 파싱 성공이지만 시설 판정 근거가 아님.

## 비 예보의 같은 지역 실내 대안

- agent/indoor.py 구현: 장소 자신의 지점 원문에 실내·전시관 입구·박물관 본관 입구·대합실이 명시되거나 HWP 본 대상 전시실 근거가 있는 경우만 실내 공간 포함으로 표시. 박물관 이름만으로 전체 실내라고 추정하지 않음. 야외 전시회·화장실만 실내인 경우 제외.
- 확인 예: 제주국립박물관(전시관 입구), 해녀박물관(본관 입구), 오설록(전망대 실내), 성산항(대합실), 빛의벙커(HWP 전시실). 모두 전체 야외 이동까지 실내라는 뜻은 아님.
- 실제 비 예보일 때 같은 시+읍면동에서 원래 필수 시설이 충족/조건부인 대안만 추가 조사. 기존 등급·순위는 유지, 별도 대안으로 최대3곳. 같은 등급 내 휠체어 경사 세 단계 적용, 근거/경사/운영·접근 조건 확인 안내. 같은 지역 근거 또는 후보가 없으면 그 사유를 표시. 해안 등 장소 성격은 실내 대안으로 변경됨을 명시.
- 구좌읍 행원리 비 모의 예보 → 같은 구좌읍 해녀박물관 실내 대안 검증. 주소 미확인인 섭지코지 자료는 같은 읍면동을 추정하지 않아 실내 대안 조사 불가로 표시.
- CLI·화면·trace/JSON에 판단 이유와 원문 근거 표시. 키 없음/예보 실패·비 아님이면 실내 추가 조사 안 함.
