# 데이터 활용 명세 초안

갱신일 2026-11-08. 대회 Q&A에 따라 허브 공개 원본·전처리 CSV·적재 DB를 제출합니다. catalog.xlsx 원본 및 그 내용이 포함된 DB·중간 파일은 제출 ZIP·GitHub에서 제외합니다. 제출 DB는 원본에서 `--no-catalog`로 새로 빌드하며 기존 DB를 수정·복사하지 않습니다. 공개 페이지 출처표 `docs/data_sources.csv`는 사용자가 직접 확인해 채우며 현재는 실제 사용한 허브 자료 5종의 행이 있으며 사용자 확인 메타데이터를 보존합니다. 빈 메타데이터는 추정하지 않습니다.

데이터 출처: 제주특별자치도·제주데이터허브, 한국관광공사, 기상청(공공누리 제1유형)

### 비사용·보조 자료 구분

허브 과거 일별 관측 `jeju_weather.csv`는 미래 여행 예보에 사용하지 않습니다. 공통 ‘제주무장애여행 데이터셋 가이드문서.hwp’는 코드·범례·ID 확인용이며 장소 시설 정보로 쓰지 않습니다. `images/`는 개수만 기록하고 OCR·시설 존재 추정을 하지 않습니다. 지도 배경은 CARTO/OpenStreetMap의 외부 타일로, 허브 접근성 판정의 출처가 아닙니다. 개발 보고서·검증 산출물은 원본을 포함할 수 있으므로 제출본에 그대로 넣지 않습니다.

## 전처리·통합 흐름

1. **준비**: 제출본의 허브 원본 CSV를 사용하며 catalog는 읽지 않습니다. 관광공사는 `collect_kto.py`가 제주 areaCode=39 목록을 전량 페이지 수집하고 상세를 조회합니다. 간격·실패·수정일을 기록합니다.
2. **스캔**: `src/raw_scan.py`가 하위 폴더를 포함해 조사합니다. 상대경로·SHA-256·양식·장소명 출처를 보존합니다. 파일명에 장소명이 없으면 장소 폴더를 쓰고 `place_name_source=folder`로 기록합니다. 동일명 파일도 다른 장소 폴더면 분리합니다. zip·공통 가이드는 제외 사유를 남기고 images는 계수만 합니다.
3. **읽기·추출**: HWP 5.x 표/문단·CSV 구조를 읽고 원본 위치를 기록합니다. 서술문은 규칙으로 추출하되 검토필요로 남깁니다. 범례만으로 시설을 만들지 않고 실제 코드·지점·좌표 연결 여부를 확인합니다.
4. **허브 장소 통합**: 원본 선언명·폴더/파일명·수동 지정·좌표와 색인을 대조합니다. 불확실한 이름·좌표 연결은 검토 목록에 남깁니다. 한림공원 같은 동일명 복수 후보는 임의 확정하지 않습니다.
5. **관광공사 보조 통합**: 기존 `integrate.judge` 이름·거리·주소 규칙으로 동일 장소를 묶고 허브/관광공사 원문 양쪽을 보존합니다. parking/restroom/exit/route/elevator/wheelchair/stroller 등 서술 필드를 있음/없음/조건부/미확인으로 추출합니다. `verify_status=검토필요(서술문)`입니다.
6. **출처·품질 보존**: 항목별 file_name/source_locator/value_raw/evidence/기준일/출처를 저장합니다. 같은 항목은 콘텐츠 기준일이 최신인 출처를 먼저 표시하고 값 차이는 충돌로 남깁니다. 최신이 사실이라는 뜻은 아닙니다. DB와 검토표·실패표·품질 보고서를 생성합니다.
7. **Agent 판정**: DB를 읽어 필수 조건·경사 순위·이용 판단·장소명·대안 유형·날씨 분기를 계산하고 추가 도구를 쓴 이유를 trace에 기록합니다. UI/CLI는 결과를 표시하며 LLM은 계산된 사실의 문장 해석/설명만 맡습니다.

현재 장소 수는 허브173+관광공사57-겹침9=221, 판정 대상122, 색인만99입니다. 충돌은 총7건(출처간5+허브내2)이며 상세 한계는 [LIMITS](LIMITS.md)에 있습니다.

## 장소 유형·거리 대안의 근거

관광공사 `contenttypeid`는 12 관광지, 14 문화시설, 15 축제·공연, 25 여행코스, 28 레포츠를 관광 대안으로, 32 숙박·38 쇼핑·39 음식점을 편의 목록으로 나눕니다. 음식점 코드는 카페도 포함할 수 있어 ‘음식점·카페’로 표시하며 세부 업종을 임의 확정하지 않습니다. 공식 필드 설명은 [관광공사 서비스 활용가이드](https://www.data.go.kr/data/15101897/openapi.do)에서 확인할 수 있습니다.

허브에는 공통 콘텐츠 유형 코드가 없어 **본 장소 원문 이름의 명시적 유형어**(공원·박물관·해수욕장·산책로·마을·코스·휴양림·식당·카페·호텔 등)만 사용합니다. 주변 업체 설명을 본 장소 유형으로 사용하지 않으며 근거가 없으면 미확인입니다. 관광공사 코드와 허브 이름은 각각 출처를 표시하고 분류는 접근성 등급을 변경하지 않습니다.

관광지 질문은 관광지 가운데 직선거리 가까운 최대5곳을 우선 후보로, 부족한 자리는 유형 미확인으로 남기고 편의 장소는 가까운 최대3곳을 별도 표시합니다. 각 목록 내 시설 등급→같은 등급 경사→거리를 적용합니다. 좌표가 없으면 거리 대안을 생략합니다.

## 기준 위치 근처 추천의 위치 자료

기준 위치는 DB → 허브 주변정보·주차장 → 브이월드 장소 검색 → 관광공사 KorService2 searchKeyword2 → 지역 사전 순으로 찾습니다. 현재 주변 CSV에는 좌표 열이 없어 주소·거리만으로 좌표를 만들지 않습니다. searchKeyword2 결과는 접근성 판정 데이터로 새로 통합하는 것이 아닌 **위치 탐색용**입니다. 업체의 위치가 검색돼도 그 업체의 접근성을 판정하지 않습니다.

지역 사전은 원본 지점 좌표(중문 주상절리, 애월한담공원, 성산항, 함덕/협재해변, 천지연폭포)를 대표 위치로 사용합니다. 제주신라호텔→중문, 성산일출봉→성산의 지역 별칭 폴백은 소재 지역만 연결하고 결과에 ‘지정 장소 실좌표 아님’을 표시합니다. 다른 업체 좌표가 확인된 것처럼 쓰지 않습니다. 지역 사전 좌표는 시설 판정에 사용하지 않습니다.

사용자가 제공한 두 CSV는 현재 `data/extra/parking_jeju.csv`, `parking_seogwipo.csv`에 있습니다. 다운로드 폴더의 원본 이름은 각각 `.csv.csv`였고, 원본은 유지한 채 요청된 파일명으로 복사했습니다. 제공자가 밝힌 출처는 [전국주차장정보표준데이터(15012896)](https://www.data.go.kr/data/15012896/standard.do), 이용조건은 ‘이용허락범위 제한 없음’입니다. 파일 안 관리기관명은 제주시청·서귀포시 교통행정과입니다. 원본 CSV와 catalog 없는 전처리 표·DB를 제출합니다.

빌드가 utf-8-sig → cp949 순서로 읽고 실제 헤더·매핑·제외 수를 로그/보고서에 남깁니다. 이번 두 파일은 utf-8-sig로 읽었습니다. 위도33.0~33.7·경도126.1~127.0의 닫힌 범위만 저장하고 좌표 누락/비수치/범위 밖은 제외합니다. 제주시 입력1,544→보존1,444(누락85·범위밖15), 서귀포113→보존113, 합계1,557곳입니다. 범위 밖에는 제주 관할이더라도 요청 좌표 범위를 벗어난 자료가 있을 수 있습니다.

Agent의 주차 조건은 `parking_general`(일반)·`parking_disabled`(장애인)로 나눕니다. 차량 이동(렌트카/렌터카/자차/운전/차 가져가/차로 가)은 일반 주차, 장애인 주차/주차구역·주차 표지는 장애인 주차로 읽습니다. 일반을 명시하지 않은 주차 요청은 같은 문장에 휠체어·장애가 있으면 장애인 주차, 그 외에는 일반 주차입니다. 차량 이동과 장애인 주차를 함께 말하면 두 조건을 모두 반영합니다. 과거 `장애인주차장` 조건 입력은 호환합니다.

일반 주차는 장소 자체의 긍정 주차 원문 → 장소 장애인 주차 있음 →500m 내 외부 주차장 →미확인 순입니다. 공란/부재/주변시설 언급만으로 현장 주차 있음으로 뒤집지 않습니다. 외부 보완은 화면 ‘근처 있음’, 내부 상태·필수 조건은 조건부, 편의 점수1점입니다. 가장 가까운1~2곳의 명칭·직선거리·구획수·요금·기준일·행 근거를 표시합니다. 편의 점수의 주차 칸은 일반 주차 요청이 있으면 일반 상태를 사용하고, 그 외에는 기존 장애인 주차 기준을 유지합니다.

장애인 주차는 장소 자체가 미확인일 때만500m 내Y를 ‘근처 장애인 주차 있음’으로 보완합니다. 장소 자체 상태는 미확인으로 보존하고 외부 보완으로 필수 조건을 조건부 충족 처리합니다. 해당 장소가 없음인 경우에는Y가 주변에 있어도 상태를 바꾸지 않습니다. 주변N·공란으로도 장소 상태를 바꾸지 않습니다.

전처리 보고서: `output/review/parking_import_report.json`, 출력 표: `output/csv/parking_lot.csv`. 같은 입력의 재빌드·재통합은 중복 누적하지 않습니다. `build_db.py`의 기존 허브/관광공사 흐름은 유지합니다.
