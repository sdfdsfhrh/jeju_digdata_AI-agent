## 배경지도·서비스 URL 제약(2026-11-09)

브이월드 WMTS는 선택 기능이며 판정·순위·구간 색의 출처가 아닙니다. 키가 없거나 인증·타일 이미지·통신에 실패하면 기존 pydeck 기본 CARTO light 벡터 지도로 전환합니다. 위성(Satellite+Hybrid)은 브이월드 성공 시만 제공됩니다. CARTO도 차단되면 배경을 확보하지 못하며 목록·코스 표시로 확인합니다. 서버 타일은 최대5분 메모리 캐시이며 파일로 저장하지 않습니다. 이미 성공한 타일도 이후 네트워크·권한 변경으로 실패할 수 있습니다.

localhost·127.0.0.1·폰 LAN주소(192.168.x.x)·센터 운영 주소는 다릅니다. 브이월드 키의 등록 서비스 URL/허용 주소와 맞지 않으면 인증이 거절될 수 있습니다. 이 앱은 키를 브라우저에 보내지 않고 서버에서 가져오며 등록된 실제 운영 URL을 Referer로 전달합니다(별도 설정이 없으면 접속 origin). 이 방식도 서비스의 권한·도메인 검사를 면제하지 않습니다. `VWORLD_SERVICE_URL`은 실제 등록된 운영 URL만 입력합니다. 포트·LAN IP 변경·센터 DLP에 따라 재확인이 필요합니다. 센터 PC·실제 폰 네트워크는 개발 PC의 좁은 화면 검증만으로 정상 동작을 보장할 수 없습니다.

출처: [브이월드 공식 WMTS](https://www.vworld.kr/dev/v4dv_wmtsguide_s001.do), [인증키 신청·관리](https://www.vworld.kr/). 실제 키로 받은 GetCapabilities에서 Base/white/midnight/Satellite/Hybrid를 확인했고 gray는 없었습니다. 지도 아래 공급자·저작권을 표시합니다. © 국토교통부 브이월드 / © CARTO, © OpenStreetMap. 지도 배경은 위치 참고용이며 조사 경로를 실제 보행로로 보정하지 않습니다.

개발 PC 실측: 동일 키로 localhost:18768·127.0.0.1:18768·예시 LAN192.168.0.100:18768을 각각 Referer로 보낸 Base 타일이 모두 정상 이미지였습니다. Satellite/Hybrid도 정상 이미지였습니다. 이는 서버 HTTP 요청 시험이며 실제 LAN 폰 접속·센터 PC 인증 시험을 대신하지 않습니다.



CARTO 검증 보완(2026-11-09, 사용자 지시 반영): Voyager 래스터 타일은 ‘API KEY REQUIRED’를 반환했지만, **기존 pydeck 기본 CARTO light 벡터 스타일은 키 없이 실제 정상 표시**됐습니다. `https://basemaps.cartocdn.com/gl/positron-gl-style/style.json` 및 `tiles.basemaps.cartocdn.com`의 벡터 타일 HTTP200, 브라우저 도로·지명·저작권 표시를 확인했습니다. 앱은 브이월드 → 이 기존 CARTO 벡터 배경 → OpenStreetMap 표준 타일 순으로 자동 대체합니다. CARTO 스타일/타일/글꼴 오류 또는12초 내 데이터 로딩 미확인 시 OSM으로 전환하고 지도 아래 실제 공급자와 출처를 표시합니다. 늦은 네트워크에서도 OSM으로 전환될 수 있습니다.

공식 CARTO 안내는 현재 외부 앱에 무료 키를 요구합니다([공식 안내](https://www.carto.com/basemaps/apikey/index.html)). 현재 벡터 성공이 장래의 키 없는 이용을 보장하지 않습니다. 다른 호스트·키를 이용한 인증 우회는 하지 않습니다. 키 없는 최종 대체는 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`이고 ‘© OpenStreetMap 기여자’를 표시합니다. 브라우저 표준 캐시·Referer를 사용하고, 화면에 필요한 타일만 요청하며 일괄 수집/오프라인 다운로드는 구현하지 않습니다([OSM 타일 이용정책](https://operations.osmfoundation.org/policies/tiles/)). OSM도 외부 연결·사용량 정책에 따라 차단될 수 있으며 운영 보장은 없습니다.


### Leaflet 지도 엔진 (2026-11-10)

Leaflet 1.9.4, BSD-2-Clause. 공식 배포: https://github.com/Leaflet/Leaflet/releases/tag/v1.9.4 / API: https://leafletjs.com/reference-1.9.4.html . JS·CSS·라이선스는 static/vendor/에 보관하고 로컬 파일을 읽어 st.components.v1.html에 삽입(CDN 호출 없음). 기존 공통 구간 분류 결과를 그대로 Leaflet 선/마커로 표시하며 판정·순위·구간 기준은 동일합니다.

기본 MAP_ENGINE=leaflet, .env에 MAP_ENGINE=pydeck을 적고 앱을 다시 실행하면 이전 엔진으로 돌아갑니다. 변경 전 코드는 backup/map_pydeck_20261110/에 보관했습니다. 브이월드 → CARTO light_all → OpenStreetMap 순 대체하며 출처는 지도 오른쪽 아래에 표시합니다. 배경이 모두 실패해도 코스/핀은 유지됩니다.

브이월드 키는 서버에서만 사용합니다. 로컬 타일 전달 서버가 기본 MAP_TILE_PORT=18769로 실행됩니다(충돌하면 빈 포트 사용). 폰·센터 PC는 앱 포트와 이 포트가 같은 네트워크에서 접근 가능해야 합니다. 차단되면 CARTO/OSM으로 대체됩니다. 앱을 HTTPS로 제공할 경우 HTTP 타일 전달이 혼합 콘텐츠로 차단될 수 있어 별도 HTTPS 역방향 프록시가 필요합니다. 이 프로젝트의 localhost/동일망 HTTP 실행을 기준으로 검증합니다. 전달 서버는 무작위 접근 경로를 사용하고 API 키/요청 URL을 로그에 남기지 않습니다.

미리보기 static/preview_normal.png·preview_satellite.png는 브이월드 제주 Base/Satellite 타일을 직접 잘랐습니다(© 국토교통부 브이월드). 외부 서비스 버튼 이미지는 사용하지 않습니다. 키가 없으면 위성 선택 불가. Streamlit1.66.1에서 components.html 실행 확인; 폐기 예정 경고가 있어 향후 Streamlit 업그레이드 시 재검증이 필요합니다.

Leaflet CARTO 보완(2026-11-10): HTTP200 API KEY REQUIRED 그림의 SHA-256을 감지하여 정상 배경으로 취급하지 않고 OSM으로 대체합니다. Leaflet 전달 서버가 막히면 브이월드/CARTO를 건너뛰고 OSM이 남습니다.

Leaflet 상세는 같은 위치의 입구·주차 라벨을 화면 픽셀만 달리 배치하며 원본 좌표는 바꾸지 않습니다. 확대 전 캡처는 전체 보기 상태를 다시 재현한 것입니다.


### 조사 자료 없는 장소의 위치와 대안(2026-11-11)
- 회색 별표는 위치 검색에서 확보한 좌표입니다. 지역 사전만 사용한 경우에는 지역 대표점이라는 한계를 표시합니다. 출입구·실제 이동 경로를 뜻하지 않으며 시설 판정에는 쓰지 않습니다. 장소의 조사 자료가 없다는 안내 뒤에, 기존 규칙으로 판정 가능한 주변 대안을 구분해 표시합니다. 거리 단위는 km이며 직선거리입니다.
- 브이월드 WMTS 요청 순서는 z/y/x입니다. Leaflet의 z/x/y 요청은 서버에서 변환하며 실제 키는 서버에서만 사용합니다. 서버는 정상 PNG를 반환했지만 격리 iframe의 crossOrigin=true 이미지 요청이 상세 확대에서 모두 tileerror로 처리되는 현상을 재현했습니다. 픽셀 읽기가 필요 없는 타일은 일반 이미지 요청(crossOrigin=false)으로 바꾸고, 확대 중 취소된 타일 한 장을 배경 전체 실패로 판단하지 않도록 보완했습니다. 로컬 PC 브라우저에서 확대 후 브이월드 유지·실제 지명/도로/출처 표시를 확인했습니다. 외부 연결·도메인 등록·로컬 타일 포트 차단 시 대체 배경을 사용합니다.
