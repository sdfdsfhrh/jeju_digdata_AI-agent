## 사용자 지정 질문

“엄마 휠체어 모시고 이번 주에 비 안 오는 날 바다 보러 가고 싶어. 화장실은 꼭 있어야 해”

- 수정 전/후 1위 삼양해수욕장. 이번 후보의 조건 충족 등급에는 측정값이 있으면서 4.76° 이하인 장소가 0곳이므로, 새 순서 적용 후에도 미측정 장소가 먼저 나오는 것이 요청한 규칙에 맞음(미측정 27곳, 기준 초과 20곳).
- 요약에 1위 경사 정보 없음(안전 확인 아님), 측정값 있는 최상위 제주 올레길 14코스(휠체어 구간) 금능리(조건 충족, 최대 8°)를 함께 표시. 측정값이 있다는 이유로 안전하다고 말하지 않음.
- 실제 LLM 화면 실행 3.819초, explain 3.149초가 최장(PC 캡처). 같은 질문의 후속 CLI 캐시 실행 0.429초, 후보 시설·경사 조사 0.364초가 최장. 수정 전에는 explain 시간이 0ms여서 실제 병목 판단에 한계가 있었음.
- 삼양해수욕장 장애인화장실 원문 “장애인 화장실 있음(구조대사무실 건물)”의 위치가 실제 LLM 설명에 반영됨. 근거: kto_detail.csv contentid=129401; field=restroom.
- 오늘 비교 시각 이전 예보는 제외하고 현재 이후 시각만 비교. 남은 시간대 없으면 오늘은 eligible=False 및 사유 표시. 이번 주 추천 대상은 해당 주만이며 표는 오늘 포함 7일 유지.
