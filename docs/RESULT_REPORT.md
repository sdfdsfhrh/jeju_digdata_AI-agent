# 닿는제주: 휠체어·유아차 여행 접근성 검증 AI Agent

## 문제 정의

이동약자와 동행자가 출발 전에 제주 여행지의 계단·경사, 주차, 장애인 화장실을 확인할 수 있도록 조사 원문과 지도 지점을 연결합니다. 전체 221곳 중 122곳이 판정 가능합니다. 제주데이터허브 5종 약 150개 파일, 관광공사 57곳, 주차장 1,557곳을 활용하며 출처 간 충돌 7건을 별도로 표시합니다.

## Agent 구조

질문에서 장소·동행자·시설·날짜를 해석하고, 다음 도구로 근거를 조회합니다. 규칙으로 판정과 순위를 계산한 뒤 이용 조건과 주의 지점을 설명합니다.

| 도구 | 역할 |
|---|---|
| 장소 검색 | 조건에 맞는 후보 조회 |
| 시설 확인 | 주차와 장애인 화장실 등 조사 근거 대조 |
| 코스 확인 | 계단·경사·단차와 지도 지점 연결 |
| 주변정보 조회 | 인근 시설과 대체 화장실 확인 |
| 기준 위치 찾기 | 장소 좌표 확인 및 직선거리 계산 |
| 날씨 확인 | 방문일 강수·풍속 조회 및 날짜 대안 안내 |

## 주요 기능

1. 장소 이름으로 이용 여부와 조사 원문을 확인합니다.
2. 필수 시설과 코스 조건을 바탕으로 장소를 추천합니다.
3. 기준 장소 근처에서 이동 목적에 맞는 후보를 찾습니다.
4. 비 예보가 있으면 강수확률이 낮은 날짜와 실내 대안을 확인합니다.
5. 판정 자료가 부족한 장소는 이를 먼저 알리고 주변 대안을 제시합니다.

## 실행 결과

- 한림공원은 일부 구간에 주의가 필요하다고 안내합니다. 조사 기록에서 장애인 주차·화장실과 계단·경사 지점을 확인할 수 있습니다. [한림공원 화면](screenshots/caution39_hanlim_mobile.jpg)
- 아쿠아플라넷 제주는 조사 자료 부족을 먼저 알리고, 위치 검색이 성공한 실행에서 약 0.3km 떨어진 섭지코지를 첫 대안으로 제시했습니다. [아쿠아플라넷 화면](screenshots/anchor40_aqua.jpg)
- 제주 신라호텔 근처 산책 질문은 위치 검색이 성공한 실행에서 약 0.79km 떨어진 퍼시픽 마리나 요트공원을 첫 후보로 제시했습니다. [신라호텔 근처 화면](screenshots/anchor40_shilla.jpg)

## 검증 방법·한계

대표 입력 30개를 규칙 모드로 각각 두 번 실행해 순위·등급이 30/30 일치했습니다. 기획서에 기록된 LLM·규칙 비교 10건에서도 후보 순서·등급이 10/10 일치했습니다. 기획서의 평균 응답 시간은 규칙 모드 0.75초, LLM 모드 약 7초입니다.

1. 허브 조사 자료는 2020~2021년 기준으로 현장 변경이 반영되기까지 시차가 있습니다.
2. 시설·코스 정보가 부족하거나 출처가 충돌하면 현장 확인이 필요합니다.
3. 거리는 직선거리입니다. 경사 참고값은 현장 통행과 안전을 보장하지 않습니다.
4. 날씨와 외부 위치 조회는 API 연결 상태에 따라 미확인으로 표시될 수 있습니다.

## 센터 활용 방안

- 이용자는 출발 전 시설과 주의 지점을 확인합니다.
- 복지관은 단체 외출 후보와 추가 확인이 필요한 지점을 고릅니다.
- 관광안내소는 문의에 원문 출처와 인근 대안을 함께 안내합니다.
- 제주도는 미확인 항목이 많거나 출처가 충돌하는 지점을 재조사 우선순위에 반영할 수 있습니다.
