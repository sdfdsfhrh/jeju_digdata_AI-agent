# 실행 오류 진단·수정 기록 (2026-11-08)

## LLM

실제 `python cli.py --check` 응답은 HTTP429, `error.code=rate_limit_exceeded`, `error.type=tokens`입니다. 요청/토큰 한도 유형이며 잔액 부족 코드나 모델 권한 코드는 아닙니다. 잔액 금액·한도 해제시각은 조회하지 않았습니다. 기존 ‘호출 한도’라는 통합 문구 대신 코드·유형·분류를 출력합니다. 실패 시 규칙 대체는 유지합니다.

[OpenAI 공식 오류 문서](https://developers.openai.com/api/docs/guides/error-codes)를 기준으로 요청 한도, 크레딧 소진, 계정 결제/사용 한도, 모델 미존재/권한, 키 인증, 원인 미제공을 분리합니다. `insufficient_quota`만 있으면 잔액과 계정 할당 중 어느 것인지 확정하지 않습니다. HTTP429만으로 요청 속도 문제라고 단정하지 않습니다. 새 월 비용 차단 기능은 없습니다.

서버 오류 본문은 출력·저장하지 않고 허용 형식 코드·유형과 고정 안내만 기록합니다. 키·계정ID·요청 헤더를 기록하지 않습니다. `--check`는 진단 목적의 실제1회 호출이며 응답 캐시와 임시 실패 차단을 우회하되 설정된 일일 제한은 지킵니다. 일반 질문의 캐시·실패 시 규칙 대체는 그대로입니다.
